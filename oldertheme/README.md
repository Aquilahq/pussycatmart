# Pussycat Mart

Pussycat Mart is the custom, lightweight WordPress theme for Pussycat Mart.

## Install

1. Copy the `pussypress` folder to `wp-content/themes/`.
2. Activate **Pussycat Mart** under Appearance → Themes.
3. Install and activate WooCommerce.
4. Add/publish products; the home shelf loads the first four published products.
5. Set the WooCommerce Cart and Checkout pages in WooCommerce → Settings → Advanced.

The theme uses native WooCommerce product objects and add-to-cart URLs, and delegates cart, checkout, payment, and order processing to WooCommerce. It does not modify WordPress core or require a page builder.
